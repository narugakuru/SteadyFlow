# Wealthfolio 资产管理工具界面设计总结文档

## 1. 整体设计语言 (Design System & Global Style)

- **色彩主题 (Color Palette):**
- 支持**浅色模式 (Light Mode)** 和 **深色模式 (Dark Mode)**。
- 以深色模式为主导：背景采用深炭灰/纯黑色（减少长时间盯盘的视觉疲劳）。
- **点缀色与功能色**：使用柔和的绿色（代表上涨、积极、健康）、橙色/红色（代表下跌、风险警告）作为数据高亮色。整体饱和度偏低，显得高级且不刺眼。

- **排版字体 (Typography):**
- 标题和标语可能使用了衬线字体（Serif）以体现优雅和传统财富管理的安全感；但在**软件内部的数据面板中，严格使用了无衬线字体（Sans-serif）**。
- 数字使用了等宽（Monospaced）或数字优化的字体，确保表格和列表中的金额上下对齐，易于阅读。

- **布局风格 (Layout Style):**
- 卡片式设计（Card-based），但弱化了卡片的边框，主要通过不同的背景色阶和留白（Padding/Margin）来划分信息区块。
- **极简主义**：去除多余的装饰线，让数据和图表成为画面的绝对核心。

## 2. 电脑端/平板端界面设计 (Desktop & iPad UI)

电脑端拥有更大的屏幕空间，其核心逻辑是“全局导航 + 高密度数据平铺 + 复杂的交互图表”。

- **全局架构:**
- 采用经典的 **左侧固定边栏 (Left Sidebar)** 作为一级导航。包含：总览、投资组合、洞察、业绩等模块入口。
- 右侧为宽大的主内容展示区。

- **核心视图分析:**

1. **总览与资产追踪页 (Investment Tracker):**

- **视觉焦点**：左上角使用大字号展示“总资产净值 (Net Worth)”及当日涨跌绝对值/百分比。
- **主图表**：占据上半屏的 **面积图 (Area Chart)**，直观展示历史总财富的增长曲线，底部带有时间轴。
- **次级信息**：图表下方采用分栏布局，左侧列出具体的账户列表（如券商账户、银行账户、退休金），右侧放置如“储蓄目标 (Saving Goals)”等辅助模块。

2. **资产明细/聚合页 (All Assets):**

- 采用 **数据表格 (Data Table)** 的形式。
- 表头包含：资产Logo/图标、代码 (Ticker)、名称、当前价格、持仓数量、总价值、涨跌幅。
- 高信息密度设计，适合深度查阅和对账。

3. **洞察与风险敞口页 (Insights & Exposure):**

- **仪表盘 (Gauge Charts)**：顶部并排使用三个半圆形的仪表盘，用于展示资金分配比例或特定的风险暴露程度。
- **树状热力图 (Treemap/Heatmap)**：占据核心位置，通过方块的**面积大小**代表持仓权重，通过颜色（绿/红）代表资产表现。这是一种非常高级且直观的投资组合可视化方式。

4. **业绩与市场对比页 (Performance):**

- **多线折线图 (Multi-line Chart)**：支持将自己的真实收益曲线与市场基准（如标普500）在同一图表中叠加对比。
- 右上角配有快速时间筛选器（1M, 3M, YTD, 1Y, MAX）。

5. **被动收入/股息追踪页 (Income):**

- 使用 **垂直柱状图 (Bar Chart)** 展示每个月的股息或利息收入，清晰展示现金流随时间的增长趋势。

## 3. 移动端界面设计 (Mobile UI)

移动端受限于屏幕宽度，其核心逻辑是“单手导航 + 垂直流式布局 + 核心数据提纯”。

- **全局架构:**
- 放弃左侧边栏，改为原生的 **底部标签栏 (Bottom Tab Bar)**，通常包含 4-5 个核心功能图标（首页、资产、图表/洞察、设置等），方便拇指操作。

- **核心视图适配与简化:**

1. **移动端总览 (Overview):**

- 顶部居中或左对齐展示总金额。
- 图表高度被压缩，但保留了核心的财富增长面积图。
- 下方原本在电脑端并排的模块，现在全部改为垂直滚动列表（先展示账户列表，再展示其他模块）。

2. **移动端资产明细 (Holdings List):**

- 将电脑端复杂的宽表格转化为 **标准的移动端列表项 (List View)**。
- **左侧**：资产Logo + 简称（主标题）+ 全称（副标题）。
- **右侧**：总价值（主数字）+ 涨跌幅（带颜色的副数字）。隐藏了对移动端不重要的次要指标，保证界面清爽。

3. **移动端洞察与可视化 (Insights):**

- 树状热力图（Treemap）被重新计算了比例，以适应手机的纵向屏幕，确保最大的几个持仓依然清晰可点。
- 下方增加了类似“最大赢家/最大输家 (Biggest winners and losers)”的水平条形图排行榜，弥补手机端看图表不够精细的问题。

4. **移动端业绩对比 (Performance):**

- 横向折线图充满屏幕宽度，最大化利用空间。图表上方紧凑地放置了时间切换Tab和具体的收益数字摘要。

## 4. 💡 给您的个人工具改进建议 (Takeaways for Your Tool)

如果您要借鉴这个软件来改进个人的资产管理工具，建议重点吸收以下几个设计理念：

1. **“渐进式明细”原则 (Progressive Disclosure):**

- 不要在首页堆砌一堆表格。首页**只放一个核心数字（总资产）和一个核心图表（趋势图）**。用户想看具体是哪只股票亏了，再点击进入下一级详情页。

2. **根据数据类型选择正确的图表 (Chart Specialization):**

- 看**整体趋势**：用面积图（Area Chart），视觉分量重。
- 看**业绩对比**：用纯线条的折线图（Line Chart），避免多重面积图互相遮挡。
- 看**仓位占比**：放弃传统的饼图（Pie Chart），改用**树状图（Treemap）**，树状图不仅能展示占比，还能同时用颜色展示盈亏，信息维度更高。
- 看**现金流/分红**：用柱状图（Bar Chart），按月分布一目了然。

3. **强调移动端的数据提纯:**

- 您在自己开发时，移动端列表千万不要做成需要左右滑动的横向表格。坚决砍掉非必要字段，采用“左标识、右数字”的上下两行排布法。

4. **色彩心理学的克制:**

- 如果是国内市场习惯，记得**红涨绿跌**（Wealthfolio是基于海外习惯的绿涨红跌）。
- 不要使用纯红或纯绿（如 `#FF0000` 或 `#00FF00`），参考图中略带灰度、饱和度较低的莫兰迪色系的红绿，看起来会更加高级且专业（例如浅绿色 `#B4D4B5` 或 暗红色 `#8B4545`）。
