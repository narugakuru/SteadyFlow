## MODIFIED Requirements

### Requirement: 资产配置纪律表

系统 SHALL 在 Dashboard 中显示资产配置纪律表。桌面端纪律表 MUST 不显示顶层表头，资产类别汇总条本身作为主列表行。汇总条 MUST 使用两行高行高布局：左侧显示大字加粗资产类别名称，中间显示加大尺寸的实际/目标进度条，右侧第一行显示大字加粗市值，第二行显示持仓盈亏金额+比例；汇总条的"市值"语义 MUST 替代旧"金额"语义。资产类别汇总条点击 SHALL 继续负责展开/收起，展开指示符 MUST 使用 `lucide-react` 矢量图标（`ChevronDown / ChevronRight` 或等价旋转图标），MUST NOT 使用 `▼ / ▶` 文本字符，且展开/收起 SHALL 带图标旋转或明细区过渡动效。汇总条进度条的状态颜色（danger/warning/success）MUST 引用统一语义色 token，MUST NOT 使用组件内联十六进制颜色。展开后的桌面端标的明细 MUST 在该资产类别内部显示不显眼的六列表头：标的、份额、现价、成本价、市值、盈亏；每个标的行 MUST 是单行数据行，标的列 MUST 将股票名称、股票代码和账户标签放在同一行，份额、现价、成本价、市值、盈亏等数据列 MUST 右对齐并整体向右侧聚集；列表头排序激活态高亮 MUST 引用语义 token 而非硬编码蓝色。移动端展开明细 MUST 使用卡片式标的条，不得渲染为桌面数据表；移动端标的卡片明细区第一行左侧 MUST 为现价，第一行右侧 MUST 为盈亏。系统 MUST 删除纪律表状态/操作列，且主列表中不显示状态 badge、调仓建议或直接操作按钮。非现金类别显示汇总持仓盈亏金额及颜色标识，现金类别持仓盈亏列显示"--"。标的条点击 SHALL 打开持仓详情 Drawer，Drawer 中提供份额、成本价、占比、买入、卖出和编辑入口；该 Drawer 的关闭入口 MUST 使用大号红色 X。编辑弹窗 SHALL 区分 amount/shares 估值模式，shares 模式使用三字段联动编辑。

#### Scenario: 纪律表主列表不显示顶层表头

- **WHEN** 用户在桌面端查看 Dashboard 纪律表
- **THEN** 纪律表主列表不显示"资产类别 / 参考指标 / 市值 / 持仓盈亏"顶层表头，直接展示资产类别汇总条

#### Scenario: 汇总条显示市值而非金额

- **WHEN** 用户查看纪律表资产类别汇总条
- **THEN** 汇总条对应核心金额语义为"市值"，展示该资产类别当前市值

#### Scenario: 汇总条使用两行大行高布局

- **WHEN** 用户在桌面端查看资产类别汇总条
- **THEN** 左侧资产类别为大字加粗，中间进度条尺寸加大，右侧第一行显示大字加粗市值，第二行显示持仓盈亏金额和比例

#### Scenario: 纪律表汇总条展开收起

- **WHEN** 用户点击某个资产类别汇总条
- **THEN** 系统展开或收起该资产类别下的标的列表，展开指示符为 lucide 矢量图标并平滑旋转，明细区以过渡方式出现或消失

#### Scenario: 进度条状态色引用语义 token

- **WHEN** 资产类别汇总条进度条根据 status 渲染颜色
- **THEN** danger/warning/success 颜色来自统一语义色 token，而不是组件内联的十六进制色值

#### Scenario: 桌面端展开持仓使用六列明细表

- **WHEN** 用户在桌面端展开某资产类别查看持仓
- **THEN** 该资产类别内部显示不显眼的表头"标的、份额、现价、成本价、市值、盈亏"，每个标的行按同一六列排列

#### Scenario: 纪律表桌面持仓行匹配账户页信息模型

- **WHEN** 用户查看桌面端展开的纪律表标的行
- **THEN** 标的列在同一行显示股票名称、股票代码和账户标签，市值列显示带币种的突出金额，盈亏列显示持仓盈亏金额和比例

#### Scenario: 纪律表桌面持仓行单行右聚集

- **WHEN** 用户查看桌面端展开的纪律表标的行
- **THEN** 整个标的行数据保持在同一行，份额、现价、成本价、市值和盈亏列右对齐并偏向右侧聚集

#### Scenario: 移动端展开持仓保持卡片

- **WHEN** 用户在移动端展开某资产类别查看持仓
- **THEN** 标的明细以移动端卡片展示，不显示桌面六列表格行

#### Scenario: 移动端标的卡片明细顺序

- **WHEN** 用户在移动端查看展开的标的卡片明细区
- **THEN** 第一行左侧显示"现价"，第一行右侧显示"盈亏"

#### Scenario: 现金类别持仓盈亏显示

- **WHEN** 纪律表展示现金类别
- **THEN** 持仓盈亏列显示"--"

#### Scenario: 纪律表不显示状态操作列

- **WHEN** 用户查看纪律表桌面端或移动端
- **THEN** 主列表不显示状态列、状态 badge、调仓建议或直接操作按钮

#### Scenario: 纪律表持仓详情 Drawer

- **WHEN** 用户点击纪律表中的某个非现金标的条
- **THEN** 系统打开该标的的持仓详情 Drawer，展示份额、现价、成本价、市值、占比、持仓盈亏和备注等详情，并显示大号红色 X 关闭入口

#### Scenario: 纪律表持仓买入

- **WHEN** 用户在持仓详情 Drawer 点击"买入"
- **THEN** 弹出 TransactionForm，交易类型为买入，并自动预填该持仓所属账户和持仓信息

#### Scenario: 纪律表持仓卖出

- **WHEN** 用户在持仓详情 Drawer 点击"卖出"
- **THEN** 弹出 TransactionForm，交易类型为卖出，并自动预填该持仓所属账户和持仓信息

#### Scenario: 纪律表编辑 shares 模式持仓

- **WHEN** 用户在持仓详情 Drawer 点击 shares 模式持仓的"编辑"
- **THEN** 弹出编辑 Dialog，显示股价/份额/市值三字段联动编辑，用户改任意字段，系统根据"最后两次编辑锁定"规则自动计算第三个字段

#### Scenario: 纪律表编辑 amount 模式持仓

- **WHEN** 用户在持仓详情 Drawer 点击 amount 模式持仓的"编辑"
- **THEN** 弹出编辑 Dialog，显示名称、市值、资产类别字段

### Requirement: Dashboard 持仓精简导出按钮

系统 SHALL 在 Dashboard 的"资产配置纪律"标题区域提供"导出持仓"按钮。按照按钮层级原则，该按钮 MUST 使用低权重（ghost/outline）样式，MUST NOT 与资产曲线区的主按钮"更新股价"使用同款主按钮配色。点击后 MUST 下载精简决策快照，仅包含总资产盈亏摘要、各类资产占比和非零市值标的持仓。

#### Scenario: 资产配置纪律区域显示按钮

- **WHEN** 用户打开 Dashboard
- **THEN** "资产配置纪律"标题区域显示"导出持仓"按钮，且按钮为低权重（ghost/outline）样式

#### Scenario: 点击导出持仓

- **WHEN** 用户点击"导出持仓"按钮
- **THEN** 系统下载精简决策快照，不包含 `raw` 与 `accountBreakdown`

### Requirement: Dashboard 纪律区快捷交易按钮

系统 SHALL 在 Dashboard 的"资产配置纪律"标题区域提供一个"交易"按钮，并将其放置在"导出持仓"按钮左侧。按照按钮层级原则，"交易"按钮 SHALL 使用次级（secondary/outline）样式而非主按钮样式，使资产曲线区的"更新股价"保持为页面唯一主操作焦点。点击后 MUST 打开通用交易弹窗，默认交易类型为买入，且默认不选择账户与持仓。

#### Scenario: 纪律区显示交易按钮

- **WHEN** 用户打开 Dashboard
- **THEN** "资产配置纪律"标题区域显示"交易"按钮，位置在"导出持仓"按钮左侧，且为次级样式

#### Scenario: 点击交易按钮打开空上下文表单

- **WHEN** 用户点击 Dashboard 纪律区的"交易"按钮
- **THEN** 系统打开交易弹窗，默认类型为"买入"，账户选择器与持仓选择器均保持为空，等待用户手动选择
