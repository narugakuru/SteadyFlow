## ADDED Requirements

### Requirement: 饼状图展示资产占比
系统 SHALL 在 Dashboard 总资产区域下方展示饼状图，默认按四个大类（股票基金/黄金/债券/现金）展示占比。

#### Scenario: 按大类展示饼状图
- **WHEN** 用户打开 Dashboard
- **THEN** 饼状图显示四个大类的占比，每个扇区标注类别名称和百分比

### Requirement: 饼状图视角切换
系统 SHALL 允许用户在"按大类"和"按标的"两种饼状图视角之间切换。

#### Scenario: 切换到按标的视角
- **WHEN** 用户点击"按标的"切换按钮
- **THEN** 饼状图切换为展示每个 Holding 的占比（含现金），每个扇区标注标的名称和百分比

#### Scenario: 切换回按大类视角
- **WHEN** 用户点击"按大类"切换按钮
- **THEN** 饼状图恢复为四个大类的占比展示

### Requirement: 饼状图颜色区分
系统 SHALL 为不同资产类别/标的使用不同颜色，同一资产类别下的标的使用该类别的色系渐变。

#### Scenario: 颜色一致性
- **WHEN** 饼状图展示按标的视角
- **THEN** 股票基金类的标的使用蓝色系，黄金类使用黄色系，债券类使用绿色系，现金使用灰色系
