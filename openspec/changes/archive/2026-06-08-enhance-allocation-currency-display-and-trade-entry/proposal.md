## Why

当前 Dashboard 与账户页默认以人民币投影视图混合展示多币种资产，纪律表与账户持仓会同时显示原币种和人民币折算值，导致用户在“按原币看持仓”和“按统一货币看总览”之间频繁切换时认知成本较高。与此同时，纪律区缺少直接新建交易的入口，资产类别汇总盈亏也只显示金额，不便快速判断收益率水平。

## What Changes

- 为 Dashboard 增加临时货币视图下拉框，按当前账户币种动态提供“默认 + 各币种”选项，并在不改写数据库的前提下实时投影总览、纪律表与再平衡金额。
- 调整纪律表与账户页持仓展示规则：默认仅显示原币种金额；切换到指定货币后统一显示该货币金额；资产类别汇总盈亏补充实时收益率。
- 在“资产配置纪律”标题区为“导出持仓”左侧新增“交易”按钮，打开交易弹窗时默认类型为买入，且默认不预选账户和持仓。
- 将资产分布图表的百分比标签统一限制为两位小数。

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `asset-allocation`: 纪律表支持按临时货币视图切换金额口径，类别汇总盈亏补充收益率，标的默认只显示原币种市值。
- `dashboard`: 总览页新增货币下拉框与纪律区快捷交易按钮，并定义默认/指定货币下的总资产与纪律表展示口径。
- `account-management`: 账户页持仓明细默认只显示原币种市值，与 Dashboard 纪律表保持一致。
- `rebalance-suggestion`: 再平衡建议金额跟随 Dashboard 临时货币视图实时投影。
- `transaction-management`: 通用交易弹窗在非持仓快捷入口打开时默认买入且不预选账户、持仓。
- `portfolio-chart`: 资产分布图的百分比标签统一显示两位小数。
- `visualization-charts`: Dashboard 资产分布相关百分比展示统一收敛为两位小数。

## Impact

- 受影响代码：Dashboard/账户/纪律表/持仓行/再平衡建议/交易弹窗/资产分布图相关组件，以及货币换算与资产快照类型定义。
- 受影响 API：继续复用 `GET /api/asset-allocation` 的原币金额、人民币折算值与汇率数据供前端实时投影，不新增持久化接口字段。
- 无新增依赖，无数据库 schema 变更；所有货币切换均基于现有汇率与原币金额实时换算，不新增持久化字段。
