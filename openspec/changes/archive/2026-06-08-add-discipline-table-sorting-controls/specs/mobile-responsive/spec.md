## ADDED Requirements

### Requirement: 纪律表移动端提供吸顶排序辅助栏

系统 SHALL 在 Dashboard 纪律表移动端卡片列表上方提供一行极简排序辅助栏。该辅助栏 MUST 使用 sticky 布局并在滚动时吸附于 Header 下方，高度为约 28px；视觉上 MUST 使用半透明白底与 backdrop blur，文字需与卡片中的金额/盈亏信息对齐。

#### Scenario: 移动端滚动时辅助栏保持吸顶

- **WHEN** 用户在移动端滚动 Dashboard 纪律表
- **THEN** 排序辅助栏固定吸附在纪律表顶部可视区域，不会随卡片内容一起滚出视口

#### Scenario: 辅助栏标签与卡片数值列对齐

- **WHEN** 用户在移动端查看纪律表卡片与排序辅助栏
- **THEN** 左侧“金额”标签与卡片主金额列左对齐，右侧“持仓盈亏”标签与卡片盈亏列右对齐

### Requirement: 纪律表移动端辅助栏显示排序状态

系统 SHALL 在移动端纪律表辅助栏中，为当前激活的排序字段显示显式状态反馈。激活项 MUST 显示圆点标记，并与桌面端共享同一字段与方向状态；未激活项 MUST 保持默认弱化样式。

#### Scenario: 移动端显示激活字段圆点

- **WHEN** 用户在移动端启用纪律表“金额”或“持仓盈亏”排序
- **THEN** 对应辅助栏标签旁显示激活圆点，且另一个标签保持默认态

#### Scenario: 刷新后辅助栏恢复本地排序状态

- **WHEN** 用户已在移动端启用某个纪律表排序字段并刷新页面
- **THEN** 辅助栏恢复到刷新前的同一激活字段与方向状态
