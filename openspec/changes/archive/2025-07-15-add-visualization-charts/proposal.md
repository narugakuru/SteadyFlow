## Why

当前所有数据（资产配置、快照历史、偏离度）都以表格和纯文字展示，投资者需要逐行阅读数字才能理解资产状态。图表是理解投资数据最直观的方式——一眼就能看出配置偏差、资产走势和结构变化，大幅提升决策效率。

## What Changes

Dashboard 新增可视化图表模块：

- **资产配置双环饼图**：外环显示实际配置，内环显示目标配置，直观对比偏差
- **偏离度柱状图**：以 0 为中心线的水平柱状图，超配红色向右、低配绿色向左，快速定位需要调整的类别
- **纪律表进度条**：在纪律表的实际占比列嵌入背景进度条 + 目标线标记，不看数字也能感知偏差
- **总资产历史走势折线图**：基于快照数据绘制总资产变化趋势（快照历史页）
- **资产类别占比堆叠面积图**：展示各类资产占比随时间的变化趋势（快照历史页）

不实现：回撤图（暂无收益率数据支持）。

## Capabilities

### New Capabilities
- `visualization-charts`: 可视化图表能力，涵盖资产配置饼图、偏离度柱状图、资产走势折线图、占比趋势面积图等所有图表组件

### Modified Capabilities
- `dashboard`: Dashboard 页面嵌入资产配置双环饼图、偏离度柱状图，纪律表增加进度条可视化
- `daily-snapshot`: 快照历史页新增总资产走势折线图和资产类别占比堆叠面积图

## Impact

- **前端组件**：新增多个图表组件（饼图、柱状图、折线图、面积图），修改 `discipline-table.tsx` 增加进度条，修改 Dashboard 页面和快照历史页布局
- **依赖**：使用项目已有的 `recharts@^3.7.0`，无需新增依赖
- **API**：快照历史 API 可能需要支持返回更多历史数据（当前按日期倒序全量返回，基本满足需求）
- **数据模型**：无变更，所有图表数据来源于现有的 snapshots 和 asset-allocation 数据
