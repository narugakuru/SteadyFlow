## ADDED Requirements

### Requirement: 类别汇总盈亏
系统 SHALL 在资产配置数据中为每个非现金资产类别计算汇总盈亏。汇总成本 = Σ 该类别所有持仓成本(CNY)；汇总盈亏 = 该类别实际金额(CNY) - 汇总成本(CNY)。

#### Scenario: 计算股票基金类别汇总盈亏
- **WHEN** 股票基金类别下有两个持仓：A 本金 ¥75,000 市值 ¥80,000，B 本金 $7,000 市值 $7,500（汇率 7.2）
- **THEN** 汇总成本 = 75000 + 7000×7.2 = ¥125,400，汇总市值 = 80000 + 7500×7.2 = ¥134,000，汇总盈亏 = +¥8,600

#### Scenario: 现金类别不显示盈亏
- **WHEN** 查看现金类别的配置数据
- **THEN** 现金类别的 totalCost 和 totalPnl 均为 0，前端不展示盈亏

### Requirement: 再平衡建议数据
系统 SHALL 在资产配置 API 返回数据中为每个资产类别包含 adjustAmount 字段，表示再平衡所需的调仓金额（CNY）。

#### Scenario: API 返回再平衡数据
- **WHEN** 前端请求 /api/asset-allocation
- **THEN** 每个 AllocationItem 包含 adjustAmount 字段，正值表示买入，负值表示卖出

## MODIFIED Requirements

### Requirement: 偏离度警告显示
系统 SHALL 根据实际占比与目标占比的偏离度，结合该类别的阈值设置，显示对应的警告状态。纪律表 SHALL 同时展示每个资产类别的汇总盈亏金额。

#### Scenario: 偏离在警告阈值内
- **WHEN** 股票基金目标 40%，实际 41%，警告阈值 3%，偏离度 +1%
- **THEN** 显示绿色正常状态

#### Scenario: 偏离达到警告阈值
- **WHEN** 股票基金目标 40%，实际 44%，警告阈值 3%，偏离度 +4%
- **THEN** 显示黄色 ⚠️ 警告，标注"超配 +4%"

#### Scenario: 偏离达到危险阈值
- **WHEN** 股票基金目标 40%，实际 46%，警告阈值 3%，危险阈值 5%，偏离度 +6%
- **THEN** 显示红色 🔴 警告，标注"超配 +6%"

#### Scenario: 低配警告
- **WHEN** 黄金目标 20%，实际 14%，警告阈值 3%，危险阈值 5%，偏离度 -6%
- **THEN** 显示红色 🔴 警告，标注"低配 -6%"

#### Scenario: 纪律表展示汇总盈亏
- **WHEN** 股票基金类别汇总成本 ¥125,400，汇总市值 ¥134,000
- **THEN** 纪律表该行显示盈亏 +¥8,600（绿色），现金行不显示盈亏
