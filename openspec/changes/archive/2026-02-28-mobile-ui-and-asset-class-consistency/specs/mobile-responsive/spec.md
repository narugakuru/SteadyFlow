## MODIFIED Requirements

### Requirement: Dialog 移动端底部弹出

所有 Dialog SHALL 在移动端（<768px）从底部弹出，宽度占满屏幕，最大高度为 100dvh（并提供 `max-h-screen` 兜底），内容可滚动，顶部显示圆角；弹窗内容不得超出手机可视区域。

#### Scenario: 移动端打开弹窗

- **WHEN** 用户在移动端触发任何弹窗（编辑持仓、交易、账户编辑等）
- **THEN** 弹窗从底部滑出，宽度 100%，最大高度不超过可视区域，内容超出时可纵向滚动

#### Scenario: 移动端关闭按钮可点击

- **WHEN** 用户在移动端查看任意弹窗头部关闭按钮
- **THEN** 关闭按钮具有清晰可见状态，最小可点击热区 MUST 不小于 44x44 像素

#### Scenario: 桌面端弹窗保持不变

- **WHEN** 用户在桌面端触发弹窗
- **THEN** 弹窗居中显示，最大宽度 512px
