## Why

当前持仓管理和交易记录的操作入口分散在不同页面，且逻辑不统一，导致用户体验割裂：
1. 账户页可以新增持仓但不能新增交易，交易页可以新增交易但不能新增持仓，用户在操作流程中频繁遇到"找不到入口"的困惑
2. 总览页纪律表的持仓编辑弹窗不区分 amount/shares 估值模式，shares 模式的持仓只能直接改市值数字，无法通过修改股价或份额来更新市值
3. 各页面之间缺少交叉导航，用户完成一个操作后无法顺畅地进入下一步

## What Changes

- 交易表单新增"新建持仓"入口：在买入/卖出选择持仓时，增加"新建持仓"选项，用户可以在交易流程中直接创建持仓并继续交易
- 账户详情页持仓列表增加"快捷交易"入口：每个持仓增加买入/卖出快捷按钮，点击后弹出交易表单并自动关联该持仓
- 总览页纪律表编辑弹窗升级为模式感知：
  - amount 模式：编辑市值字段
  - shares 模式：三字段联动编辑（股价、份额、市值），用户编辑任意两个字段，第三个自动计算，被计算的字段用视觉样式区分
- 账户详情页的持仓编辑弹窗同步支持 shares 模式三字段联动编辑
- 各页面增加交叉导航链接：账户持仓可跳转到该持仓的交易记录，交易记录可跳转到关联持仓所在账户

## Capabilities

### New Capabilities

_无新增独立能力模块_

### Modified Capabilities

- `holding-management`: 持仓编辑升级为三字段联动模式（股价/份额/市值），支持"最后两次编辑锁定，第三个自动计算"的交互逻辑；纪律表内联编辑弹窗需区分 amount/shares 模式
- `transaction-management`: 交易表单的持仓选择器增加"新建持仓"内联入口；账户详情页持仓列表增加快捷交易入口
- `dashboard`: 纪律表内联编辑弹窗升级为模式感知编辑
- `navigation-layout`: 各页面间增加持仓↔交易的交叉导航链接

## Impact

- 前端组件改动：`holdings-panel.tsx`（三字段联动编辑 + 快捷交易按钮）、`discipline-table.tsx`（InlineEditDialog 升级）、`transactions/page.tsx`（TransactionForm 增加新建持仓入口）
- API 无需改动：现有 holdings PUT API 已支持 price/shares/marketValue 字段更新
- 无数据模型变更
- 无破坏性变更
