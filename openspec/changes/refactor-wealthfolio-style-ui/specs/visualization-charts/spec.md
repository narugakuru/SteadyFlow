## ADDED Requirements

### Requirement: 总览绿色填充资产面积图

系统 SHALL 在总览页提供绿色填充资产面积图，用于展示当前用户净值历史中的总资产走势。该图表 MUST 使用统一数值格式化函数展示金额，并在 Tooltip 中显示日期与总资产金额。

#### Scenario: 面积图正常渲染

- **WHEN** 总览页收到至少两个净值图表点
- **THEN** 页面使用绿色线条与半透明绿色填充渲染资产面积图

#### Scenario: Tooltip 展示金额

- **WHEN** 用户悬停在面积图某个点上
- **THEN** Tooltip 显示该日期和格式化后的总资产金额

### Requirement: 洞察占比图表

系统 SHALL 为洞察页的货币占比、账户占比、资产类别占比提供可视化图表。图表 MUST 展示名称、金额和百分比，并在数据不足时提供空状态。

#### Scenario: 洞察图表显示百分比

- **WHEN** 洞察页某账户占比为 `38.584`
- **THEN** 图表标签或 Tooltip 使用统一百分比格式展示该占比

#### Scenario: 洞察图表空状态

- **WHEN** 洞察页总资产为 0
- **THEN** 占比图表区域显示空状态，不显示 NaN 或错误比例

### Requirement: 当前持仓热力图可视化

系统 SHALL 为洞察页提供当前持仓热力图。热力图块大小 MUST 表示持仓市值权重，颜色 MUST 表示当前盈亏比例，Tooltip MUST 展示持仓名称、账户、当前市值、盈亏金额与盈亏比例。

#### Scenario: 热力图 Tooltip

- **WHEN** 用户悬停在某个持仓热力图块上
- **THEN** Tooltip 显示持仓名称、账户、当前市值、盈亏金额与盈亏比例

#### Scenario: 热力图过滤零市值持仓

- **WHEN** 某持仓当前市值为 0
- **THEN** 该持仓不参与热力图面积布局
