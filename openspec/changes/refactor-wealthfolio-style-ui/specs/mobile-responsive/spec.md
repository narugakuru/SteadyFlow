## ADDED Requirements

### Requirement: 移动端应用外壳导航

系统 SHALL 为新的左侧边栏应用外壳提供移动端导航方案。移动端 MUST 能访问总览、洞察、账户、活动、净值、管理（admin only）和设置入口，且导航不得遮挡页面主要内容。

#### Scenario: 移动端打开导航

- **WHEN** 用户在移动端打开应用并触发导航入口
- **THEN** 系统展示包含总览、洞察、账户、活动、净值和必要角色项的导航面板或等价移动导航

#### Scenario: 移动端设置入口

- **WHEN** 用户在移动端触发设置入口
- **THEN** 系统打开现有设置弹窗或移动端设置面板

#### Scenario: 移动端 admin 导航

- **WHEN** `role="admin"` 的用户在移动端打开导航
- **THEN** 导航中显示“管理”

#### Scenario: 移动端普通用户导航

- **WHEN** `role="user"` 的用户在移动端打开导航
- **THEN** 导航中不显示“管理”

## MODIFIED Requirements

### Requirement: 响应式页面容器

所有页面容器 SHALL 适配新的应用外壳。移动端（<768px）主内容区域使用较小内边距并占满可用宽度；桌面端主内容区域显示在侧边栏右侧并使用稳定边距。总览与洞察页面 MAY 使用更宽的图表区域，操作型页面 MUST 保持表格、卡片和表单不溢出。

#### Scenario: 移动端页面容器

- **WHEN** 用户在宽度小于 768px 的设备上访问任意页面
- **THEN** 页面内容区域使用紧凑水平内边距，内容占满可用宽度且不被导航遮挡

#### Scenario: 桌面端页面容器

- **WHEN** 用户在宽度大于等于 768px 的设备上访问任意页面
- **THEN** 页面内容区域位于侧边栏右侧，使用统一桌面边距并保持可读

#### Scenario: 图表页面移动端不溢出

- **WHEN** 用户在移动端访问总览或洞察页面
- **THEN** 图表、热力图、时间范围控件和卡片不得横向溢出屏幕
