## ADDED Requirements

### Requirement: Dashboard 纪律表支持类别内明细三态排序

系统 SHALL 允许用户通过 Dashboard 纪律表中的“金额”与“持仓盈亏”排序控件，对每个资产类别展开后的明细列表进行临时排序。排序状态 MUST 按 `降序 -> 升序 -> 默认` 循环；其中“默认” MUST 恢复为后端返回的数据库手动排序顺序。排序比较前 MUST 先将不同币种金额与盈亏折算为统一货币后再比较。排序作用域 MUST 限定在单个资产类别内部，资产类别顶层顺序不得被打乱。

#### Scenario: 首次点击金额按类别内金额降序

- **WHEN** 用户点击纪律表中的“金额”排序控件，且此前未启用该字段排序
- **THEN** 每个资产类别展开后的明细列表均按各自金额从大到小排序，资产类别顶层顺序保持不变

#### Scenario: 第二次点击同一字段按升序

- **WHEN** 用户已经启用“持仓盈亏”的降序排序后再次点击同一控件
- **THEN** 每个资产类别展开后的明细列表改为按各自持仓盈亏从小到大排序，资产类别顶层顺序仍保持不变

#### Scenario: 第三次点击恢复数据库默认顺序

- **WHEN** 用户已经启用某个纪律表字段的升序排序后第三次点击同一控件
- **THEN** 每个资产类别展开后的明细列表恢复为数据库返回的默认手动顺序

#### Scenario: 跨币种持仓按统一货币比较

- **WHEN** 同一资产类别下同时存在 CNY、USD、HKD 持仓，且用户启用金额或持仓盈亏排序
- **THEN** 系统先将这些持仓折算到统一货币后再比较顺序，而不是直接按原币数字排序

### Requirement: Dashboard 纪律表排序偏好本地持久化

系统 SHALL 将 Dashboard 纪律表当前使用的排序字段与方向持久化到本地存储。用户刷新页面或重新进入网站后，纪律表 MUST 恢复为最近一次保存的本地排序偏好；若本地没有有效偏好，则 MUST 使用数据库默认顺序。

#### Scenario: 刷新后恢复最近排序偏好

- **WHEN** 用户已在纪律表中启用“金额降序”或“持仓盈亏升序”，随后刷新页面
- **THEN** 页面重新加载后纪律表仍使用刷新前的同一排序字段与方向

#### Scenario: 本地无有效偏好时回退默认顺序

- **WHEN** 用户首次进入 Dashboard，或本地存储中不存在有效纪律表排序偏好
- **THEN** 纪律表按数据库默认顺序展示明细列表，不启用临时排序高亮

### Requirement: Dashboard 桌面端纪律表表头显示排序状态

系统 SHALL 在 Dashboard 桌面端纪律表的“金额”与“持仓盈亏”表头右侧显示 12px 双向箭头，并使用可感知的激活样式反馈当前排序状态。默认态图标与文字 MUST 使用静止/默认颜色；激活态 MUST 与当前方向箭头一起高亮。

#### Scenario: 桌面端默认态显示静止箭头

- **WHEN** 用户在桌面端查看未启用临时排序的纪律表
- **THEN** “金额”与“持仓盈亏”表头右侧均显示默认色的双向箭头，且表头文字不高亮

#### Scenario: 桌面端激活态显示方向高亮

- **WHEN** 用户在桌面端启用纪律表的“持仓盈亏”降序或升序排序
- **THEN** 对应表头文字与当前方向箭头高亮显示，另一个表头维持默认态
