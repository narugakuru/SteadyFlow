## Context

当前账户列表使用 `div` 单行布局，每个账户一行，信息用 flex 水平排列。纪律表已经使用 `<table>` 结构，视觉效果好、数据对齐清晰。本次将账户列表也改为 table 结构，保持风格统一。

## Goals / Non-Goals

**Goals:**
- 账户列表改为 table 布局，列对齐展示总额、现金、持仓、持仓数量
- 保持现有交互：行可点击进入持仓详情，操作按钮编辑/删除
- 与纪律表视觉风格一致

**Non-Goals:**
- 不改变 AccountList 的 props 接口
- 不改变 API 或数据模型
- 不添加排序/筛选功能

## Decisions

### 1. 使用 HTML table 而非 shadcn Table 组件
**选择**: 直接使用 `<table>` 标签 + Tailwind 样式，与纪律表保持一致。
**理由**: 纪律表已经用原生 table，保持代码风格统一，无需额外组件。

### 2. 列定义
**选择**: 账户名称 | 总额 | 现金 | 持仓 | 持仓数 | 操作
**理由**: 覆盖用户关心的核心信息，与提案一致。

## Risks / Trade-offs

- [窄屏适配] → 列较多时可能需要水平滚动，但本应用为桌面端使用，可接受
