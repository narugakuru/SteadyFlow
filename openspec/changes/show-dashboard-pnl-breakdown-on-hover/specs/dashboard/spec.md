## MODIFIED Requirements

### Requirement: 总览当前盈亏快照

系统 SHALL 在总览核心资产区域展示账户总盈亏信息，至少包含账户总盈亏金额与账户总盈亏百分比。账户总盈亏金额 MUST 使用现有 `totalPnl = realizedPnl + unrealizedPnl` 口径实时计算，不得作为独立持久化字段存储。账户总盈亏百分比 MUST 作为当前快照指标展示，计算基准为 `estimatedPrincipalCny = totalAssetCny - totalPnl`。当基准无效或小于等于 0 时，百分比 MUST 显示为 `--`。总览净值视图 MUST 保持原有左侧总资产与账户总盈亏的简洁常驻层级，不得在右侧或左侧常驻新增持仓盈亏/了结盈亏拆分。用户将鼠标悬停到左侧总资产数字或账户总盈亏数字区域时，系统 SHALL 显示一个轻量提示浮层，展示持仓盈亏与了结盈亏的金额和百分比。所有盈亏金额与百分比的正负颜色 MUST 按设置中的 A股或美股涨跌颜色模式渲染。

#### Scenario: 总览核心区展示账户总盈亏

- **WHEN** 用户打开 Dashboard 且总资产数据加载完成
- **THEN** 总览核心区显示账户总盈亏金额与账户总盈亏百分比

#### Scenario: 账户总盈亏实时计算

- **WHEN** 当前用户持仓盈亏为 `8000`，了结盈亏为 `3500`
- **THEN** 页面展示账户总盈亏为 `11500`

#### Scenario: 无交易或无持仓时显示

- **WHEN** 当前用户没有卖出交易且没有浮动盈亏
- **THEN** 账户总盈亏金额显示为 `0`，账户总盈亏百分比按有效分母计算或显示为 `--`

#### Scenario: 当前总盈亏百分比

- **WHEN** `totalAssetCny=110000` 且 `totalPnl=10000`
- **THEN** 总览页显示账户总盈亏百分比约为 `10%`

#### Scenario: 盈亏百分比分母无效

- **WHEN** `totalAssetCny - totalPnl <= 0`
- **THEN** 账户总盈亏百分比显示为 `--`

#### Scenario: 默认不常驻展示拆分盈亏

- **WHEN** 用户打开 Dashboard 净值视图且没有悬停总资产数字或账户总盈亏数字区域
- **THEN** 总览核心区不常驻显示持仓盈亏与了结盈亏拆分

#### Scenario: 悬停资产数字显示拆分盈亏

- **WHEN** 用户将鼠标悬停到左侧总资产数字
- **THEN** 页面显示包含持仓盈亏与了结盈亏金额/百分比的轻量提示浮层

#### Scenario: 悬停盈亏数字显示拆分盈亏

- **WHEN** 用户将鼠标悬停到左侧账户总盈亏金额或百分比
- **THEN** 页面显示包含持仓盈亏与了结盈亏金额/百分比的轻量提示浮层

#### Scenario: 盈亏颜色遵循全局颜色模式

- **WHEN** 用户在设置中切换 A股或美股涨跌颜色模式
- **THEN** 总览账户总盈亏、持仓盈亏与了结盈亏的金额和百分比颜色均按当前模式更新
