## ADDED Requirements

### Requirement: 账户持仓明细使用响应式 HoldingRow

系统 SHALL 在账户管理页的账户持仓明细中使用统一的响应式 HoldingRow。桌面端 HoldingRow MUST 展示为单行数据网格，移动端 MUST 展示为高密度信息卡片。买入、卖出和编辑操作 MUST 收纳在行内 `...` 菜单中；账户页删除持仓操作 MUST 保持为最右侧独立小垃圾桶按钮，不收入 `...` 菜单。

#### Scenario: 账户页桌面端持仓行

- **WHEN** 用户在桌面端查看账户页持仓明细
- **THEN** 每个持仓以单行数据网格展示资产信息、份额、价格信息、总金额/占比、盈亏和操作区，数字列右对齐

#### Scenario: 账户页持仓菜单操作

- **WHEN** 用户在账户页打开某持仓的 `...` 菜单
- **THEN** 菜单提供买入、卖出和编辑操作，不包含删除

#### Scenario: 账户页持仓删除仍为独立按钮

- **WHEN** 用户在账户页查看某持仓行
- **THEN** 删除持仓入口显示为最右侧独立小垃圾桶按钮，并继续沿用现有删除校验和确认流程

#### Scenario: 账户页移动端持仓卡片

- **WHEN** 用户在移动端查看账户页持仓明细
- **THEN** 每个持仓以高密度信息卡片展示，右上角提供 `...` 菜单，删除入口仍独立显示且可点击
