## ADDED Requirements

### Requirement: 累计 TWR 收益率曲线视图

系统 SHALL 在净值/总览相关图表区提供累计 TWR 收益率曲线视图，与资产价值面积图明确区分。收益率曲线 MUST 渲染 0% 基准线，Y 轴 MUST 以统一百分比格式展示累计 TWR，Tooltip MUST 展示日期、累计 TWR 百分比与当日组合市值。该视图表示投资业绩，资产面积图表示资产价值趋势，两者语义 MUST NOT 混淆。

#### Scenario: 收益率曲线渲染 0% 基准线

- **WHEN** 用户切换到收益率曲线视图且存在至少两个市值点
- **THEN** 图表以累计 TWR 折线展示，并渲染 0% 基准线

#### Scenario: 收益率视图与资产视图可切换

- **WHEN** 用户在图表区切换"净值 / 收益率"
- **THEN** 系统在资产面积图与累计 TWR 折线图之间切换，且不混淆两者语义

#### Scenario: 收益率 Tooltip 展示百分比与市值

- **WHEN** 用户悬停在收益率曲线某点上
- **THEN** Tooltip 显示该日期、累计 TWR 百分比与当日组合市值

#### Scenario: 数据不足时的空状态

- **WHEN** 净值快照少于两个点
- **THEN** 收益率曲线区域显示空状态，不渲染 NaN 或错误比例
