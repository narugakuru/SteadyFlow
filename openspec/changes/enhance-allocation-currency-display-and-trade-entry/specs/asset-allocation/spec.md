## ADDED Requirements

### Requirement: 资产配置纪律表支持临时货币视图

系统 SHALL 为资产配置纪律表提供临时货币视图。默认视图下，资产类别金额、类别汇总盈亏与再平衡基准保持 CNY，展开的持仓与现金明细显示原始账户币种金额；当用户切换到指定货币时，纪律表中的资产类别金额、类别汇总盈亏、持仓/现金明细与再平衡金额 MUST 全部基于数据库中的原币金额和实时汇率换算为目标币种展示，且该视图选择 MUST NOT 持久化到数据库或本地存储。

#### Scenario: 默认视图保持总览 CNY 且持仓显示原币

- **WHEN** 用户首次进入 Dashboard，货币下拉保持“默认”
- **THEN** 纪律表资产类别金额与类别汇总盈亏显示为 CNY，展开后的外币持仓与外币现金明细仅显示原始账户币种金额

#### Scenario: 切换到人民币视图

- **WHEN** 用户将 Dashboard 货币下拉切换到“人民币”
- **THEN** 纪律表中的资产类别金额、类别汇总盈亏、持仓/现金明细与再平衡金额全部实时换算并显示为 CNY

#### Scenario: 切换到美元视图

- **WHEN** 用户将 Dashboard 货币下拉切换到“美元”
- **THEN** 纪律表中的资产类别金额、类别汇总盈亏、持仓/现金明细与再平衡金额全部实时换算并显示为 USD

## MODIFIED Requirements

### Requirement: 偏离度警告显示

系统 SHALL 在纪律表中仅显示"状态"列（移除独立的"偏离"列），状态中包含偏离方向和幅度信息。纪律表 SHALL 同时展示每个非现金资产类别的汇总盈亏金额与盈亏比例；现金行不显示盈亏。

#### Scenario: 超配警告状态

- **WHEN** 股票目标 40%，实际 44%，全局警告阈值 3%
- **THEN** 状态列显示 "⚠️ 超配 +4%"

#### Scenario: 正常状态

- **WHEN** 股票目标 40%，实际 41%，全局警告阈值 3%
- **THEN** 状态列显示 "✅ 正常"

#### Scenario: 纪律表展示汇总盈亏金额与比例

- **WHEN** 股票类别汇总成本 ¥125,400，汇总市值 ¥134,000
- **THEN** 纪律表该行显示盈亏 +¥8,600（绿色）以及收益率 +6.86%

### Requirement: 纪律表可展开行

系统 SHALL 允许用户点击纪律表中的资产类别行来展开/收起该类别下的标的详情列表。展开后显示该类别下所有持仓标的，每个标的显示名称、所属账户、市值（默认原币或当前指定视图货币）、收益率、占总资产比例。对于非现金类别，纪律表使用的持仓数据源 MUST 在数据库检索阶段过滤零市值标的，不得先查询零市值记录再依赖展示层隐藏；零市值判定 MUST 同时兼容“直接市值字段”和“份额 × 价格”两种市值来源。若某些兼容调用链路仍保留了金额为 0 的项，排序时 MUST 将其置于末位（次级按既有排序字段），不得影响非 0 金额标的的相对顺序。

#### Scenario: 展开股票类别仅显示数据库已过滤后的非零金额标的

- **WHEN** 用户点击纪律表中"股票"行，且该类别下同时存在金额为 0 与非 0 的标的
- **THEN** 系统在纪律专用持仓查询阶段排除金额为 0 的标的，行下方仅展示非 0 金额标的明细，显示名称、账户、市值、收益率与占比

#### Scenario: 默认视图下外币标的显示原币

- **WHEN** 用户在默认视图展开某个外币资产类别，标的所属账户币种为 USD
- **THEN** 该标的市值显示为美元原值，不再额外默认显示人民币近似市值

#### Scenario: 指定货币视图下统一显示目标币种

- **WHEN** 用户将 Dashboard 货币视图切换到 CNY 或 USD 后展开某个资产类别
- **THEN** 该类别下所有持仓与现金明细的金额统一实时换算并显示为当前目标币种

#### Scenario: shares 模式零市值标的不会进入纪律明细

- **WHEN** 某 shares 模式标的的 `shares × price = 0`
- **THEN** 系统即使持久化字段存在旧值，也不得将该标的返回到纪律表展开明细中

#### Scenario: amount 模式零市值标的不会进入纪律明细

- **WHEN** 某 amount 模式标的的当前 `marketValue = 0`
- **THEN** 系统不得将该标的返回到纪律表展开明细中

#### Scenario: 保留 0 金额项时自动末位排序

- **WHEN** 某调用链路返回了金额为 0 的标的用于兼容展示
- **THEN** 系统将所有金额为 0 的标的排序到当前类别明细末尾，非 0 金额标的顺序保持稳定

#### Scenario: 展开现金类别

- **WHEN** 用户点击纪律表中"现金"行
- **THEN** 行下方展开显示各账户的现金余额明细，并遵循金额为 0 项默认不展示规则与当前货币视图

#### Scenario: 收起类别

- **WHEN** 用户再次点击已展开的类别行
- **THEN** 标的详情列表收起
