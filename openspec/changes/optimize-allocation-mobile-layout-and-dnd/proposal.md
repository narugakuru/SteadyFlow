## Why

资产配置纪律在移动端存在可读性与可操作性问题：金额为 0 的标的仍占据展示空间，资产类别卡片信息拥挤导致大金额时溢出，且移动端拖拽排序释放后会回弹，影响排序可信度与使用效率。该问题直接影响核心日常复盘场景，需要优先修复。

## What Changes

- 调整纪律明细展示规则：金额为 0 的标的不在纪律明细中显示，同时排序时将金额为 0 的项自动置于末尾。
- 优化移动端资产类别卡片布局为三行垂直结构：第一行标题+进度，第二行主金额大字，第三行盈亏+状态+调仓操作。
- 修复移动端资产类别内拖拽排序回弹问题，确保释放后 UI 顺序与持久化顺序一致。
- 保持桌面端表格布局与既有交互不变，避免回归风险。

## Capabilities

### New Capabilities

- 无

### Modified Capabilities

- `asset-allocation`: 调整纪律展开明细的展示与排序约束，明确金额为 0 的标的隐藏与末位排序规则。
- `mobile-responsive`: 调整移动端纪律卡片信息排布要求，确保大金额与状态信息在窄屏可读。
- `discipline-overview-sorting`: 补充拖拽释放后顺序稳定性与持久化一致性要求，修复移动端回弹。

## Impact

- 前端：总览页资产配置纪律组件、移动端卡片布局、拖拽交互状态管理。
- 后端/API：纪律明细数据排序与过滤逻辑（如在聚合层或返回层实现 0 金额过滤与末位规则）。
- 测试：新增移动端布局回归、拖拽完成态回归、0 金额明细可见性回归。
