## MODIFIED Requirements

### Requirement: 纪律表可展开行

系统 SHALL 允许用户点击纪律表中的资产类别行来展开/收起该类别下的标的详情列表。展开后显示该类别下所有持仓标的，每个标的显示名称、所属账户、市值(CNY)、收益率、占总资产比例。对于非现金类别，纪律表使用的持仓数据源 MUST 在数据库检索阶段过滤零市值标的，不得先查询零市值记录再依赖展示层隐藏；零市值判定 MUST 同时兼容“直接市值字段”和“份额 × 价格”两种市值来源。若某些兼容调用链路仍保留了金额为 0 的项，排序时 MUST 将其置于末位（次级按既有排序字段），不得影响非 0 金额标的的相对顺序。

#### Scenario: 展开股票类别仅显示数据库已过滤后的非零金额标的

- **WHEN** 用户点击纪律表中"股票"行，且该类别下同时存在金额为 0 与非 0 的标的
- **THEN** 系统在纪律专用持仓查询阶段排除金额为 0 的标的，行下方仅展示非 0 金额标的明细，显示名称、账户、市值、收益率与占比

#### Scenario: shares 模式零市值标的不会进入纪律明细

- **WHEN** 某 shares 模式标的的 `shares × price = 0`
- **THEN** 系统即使持久化字段存在旧值，也不得将该标的返回到纪律表展开明细中

#### Scenario: amount 模式零市值标的不会进入纪律明细

- **WHEN** 某 amount 模式标的的当前 `marketValue = 0`
- **THEN** 系统不得将该标的返回到纪律表展开明细中

#### Scenario: 保留 0 金额项时自动末位排序

- **WHEN** 某调用链路返回了金额为 0 的标的用于兼容展示
- **THEN** 系统将所有金额为 0 的标的排序到当前类别明细末尾，非 0 金额标的顺序保持稳定

#### Scenario: 展开现金类别

- **WHEN** 用户点击纪律表中"现金"行
- **THEN** 行下方展开显示各账户的现金余额明细，并遵循金额为 0 项默认不展示规则

#### Scenario: 收起类别

- **WHEN** 用户再次点击已展开的类别行
- **THEN** 标的详情列表收起
