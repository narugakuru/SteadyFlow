## Requirements

### Requirement: 再平衡建议计算

系统 SHALL 基于每个资产类别的目标占比和实际占比，计算再平衡调仓金额。计算公式：adjustAmount = (targetPct / 100) × totalAssetCny - actualValue。正值表示需要买入，负值表示需要卖出。

#### Scenario: 超配类别建议卖出

- **WHEN** 股票基金目标 40%，实际 45%，总资产 ¥400,000
- **THEN** adjustAmount = 0.40 × 400000 - 180000 = -20000，建议卖出 ¥20,000

#### Scenario: 低配类别建议买入

- **WHEN** 黄金目标 20%，实际 14%，总资产 ¥400,000
- **THEN** adjustAmount = 0.20 × 400000 - 56000 = 24000，建议买入 ¥24,000

#### Scenario: 配置正常无需调整

- **WHEN** 债券目标 25%，实际 25.5%，偏离在警告阈值内
- **THEN** adjustAmount 接近 0，标记为"无需调整"

### Requirement: 再平衡建议展示

系统 SHALL 在纪律表下方展示再平衡建议模块，以卡片列表形式显示需要调整的资产类别。每行显示：类别名称、当前偏离度、建议操作（买入/卖出）及金额。

#### Scenario: 展示多个调仓建议

- **WHEN** 存在超配和低配的资产类别
- **THEN** 再平衡建议模块显示所有需要调整的类别，超配类别显示"建议卖出 ¥X"（红色），低配类别显示"建议买入 ¥X"（绿色）

#### Scenario: 所有类别均衡

- **WHEN** 所有资产类别偏离度均在警告阈值内
- **THEN** 再平衡建议模块显示"当前配置均衡，无需调整"

### Requirement: 再平衡建议跟随 Dashboard 临时货币视图

系统 SHALL 让 Dashboard 再平衡建议模块中的建议金额跟随当前临时货币视图实时投影。默认视图下继续显示 CNY；切换到指定币种后，建议买入/卖出金额 MUST 统一显示为该目标币种，且不得改写数据库中的资产价格或调仓基准。

#### Scenario: 默认视图显示人民币建议金额

- **WHEN** 用户保持 Dashboard 货币视图为“默认”
- **THEN** 再平衡建议继续显示“建议买入/卖出 ¥X”

#### Scenario: 美元视图显示美元建议金额

- **WHEN** 用户将 Dashboard 货币视图切换到 USD
- **THEN** 再平衡建议统一显示“建议买入/卖出 $X”，金额由现有原币资产和汇率实时换算得到

### Requirement: 再平衡建议位置

系统 SHALL 将再平衡建议组件放置在 Dashboard 的纪律表下方、账户列表上方。

#### Scenario: Dashboard 布局顺序

- **WHEN** 用户打开 Dashboard
- **THEN** 页面从上到下依次为：总资产卡片 → 饼图 → 纪律表 → 再平衡建议 → 账户列表
